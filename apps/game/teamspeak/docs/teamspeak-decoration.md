# Оформление TeamSpeak 6

Дата изменения: 2026-09-05.

## Параметры сервера

- Имя: `🎮 Ammatias Game Hub`.
- Для новых подключений установлен пароль; значение хранится только у владельца и не фиксируется в репозитории.
- Добавлены приветственное сообщение и краткое сообщение хоста.
- Новым Guest-клиентам TS6 Manager отправляет отдельное приватное приветствие с персональной кнопкой подтверждения; до подтверждения доступ ограничен лобби, после него выдаётся группа `Verified`.
- Установлен предоставленный владельцем красно-белый значок с драконом. Исходник находится в `assets/teamspeak/server-logo.ico`, а применённая версия — `assets/teamspeak/server-logo-ts6.png` (PNG, 64×64, 7986 байт).
- Установлен панорамный баннер `Ammatias Game Hub` в графитово-красной стилистике. Исходник сохранён в `assets/teamspeak/server-banner-source.png`, применённая версия рекомендуемого для клиента TS6 размера 630×236 — в `assets/teamspeak/server-banner-ts6.jpg`.
- Баннер загружен во встроенное файловое хранилище канала `🏠 Лобби` и подключён через `ts3image://voice.example.com?port=9987&channel=1&path=/&filename=teamspeak-server-banner-ts6.jpg`. Замените hostname на свой; файл передаётся клиенту штатным TeamSpeak File Transfer через опубликованный порт `30033/tcp`.

## Постоянные каналы

Все 18 каналов имеют постоянный тип. Голосовые каналы также предоставляют встроенный текстовый чат TeamSpeak, кроме явно ограниченных каналов ниже. Главные каналы игр и общения используются только как разделители: подключение к ним запрещено значением `i_channel_needed_join_power=100`.

```text
🏠 Лобби [без голоса]
├─ ⛏ Minecraft [разделитель]
│  └─ Techno
├─ 🎯 Counter-Strike 2 [разделитель]
│  ├─ 🏆 Премьер
│  ├─ 💥 Команда 1
│  ├─ 💥 Команда 2
│  └─ 🎓 Тренировка
├─ 🛡 World of Tanks [разделитель]
│  ├─ ⚔ Взвод 1
│  ├─ ⚔ Взвод 2
│  └─ 🏰 Клановые бои
├─ 🤖 R.E.P.O. [разделитель]
│  └─ 📦 Вылазка
└─ ☕ Общение [разделитель]
   ├─ 💬 Разговорная
   ├─ 💬 Музыка
   └─ 🌙 AFK [без голоса и отправки сообщений]
```

Каналам заданы темы, описания и максимальное качество кодека. Для музыкального канала используется кодек Opus Music. В `🏠 Лобби` и `🌙 AFK` установлено требование talk power `100`; для AFK канальное разрешение `b_client_channel_textmessage_send=0` запрещает отправку сообщений. На `⛏ Minecraft`, `🎯 Counter-Strike 2`, `🛡 World of Tanks`, `🤖 R.E.P.O.` и `☕ Общение` установлено требование join power `100`, поэтому они работают как заголовки разделов; обычные клиенты и Server Admin с join power `75` подключаются только к дочерним голосовым каналам.

Главным игровым каналам назначены отдельные 32×32 PNG-значки:

| Канал | Файл | CRC32 |
|---|---|---:|
| `⛏ Minecraft` | `assets/teamspeak/channel-minecraft-ts6.png` | `1753106380` |
| `🎯 Counter-Strike 2` | `assets/teamspeak/channel-cs2-ts6.png` | `2024775841` |
| `🛡 World of Tanks` | `assets/teamspeak/channel-wot-ts6.png` | `622011093` |
| `🤖 R.E.P.O.` | `assets/teamspeak/channel-repo-ts6.png` | `2053741198` |

Скрипт `tools/prepare_ts_icons.py` добавляет к PNG безопасный служебный блок, не меняя изображение, чтобы CRC32 укладывался в поддерживаемый TeamSpeak знаковый диапазон.

## Способ применения

Для первоначального оформления временно включались внутренние HTTP и SSH ServerQuery без публикации портов на хосте. Изменения Compose и `.env` выполнялись штатным API Dockhand в окружении `120 - TeamSpeak`. Значки переданы штатным протоколом TeamSpeak File Transfer, а ссылки и разрешения назначены через ServerQuery. Позже оба Query-интерфейса снова включены для постоянной интеграции с TS6 Manager, но доступны только в Docker-сети `frontend`; наружу по-прежнему опубликованы только `9987/udp` и `30033/tcp`.

Первый вариант баннера через Homepage оставлен как резервный, но активная настройка использует внутренний `ts3image://` URL. Значки и баннер повторно скачаны через TeamSpeak File Transfer после загрузки; контрольные суммы скачанных файлов совпали с исходниками.
