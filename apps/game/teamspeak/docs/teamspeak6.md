# Сервер TeamSpeak 6

Дата развёртывания: 2026-09-05. Последнее изменение: 2026-09-05.

## Размещение

- Узел: выделенный Docker-host TeamSpeak; приватный адрес в публичной копии не фиксируется.
- Compose project и контейнер: `teamspeak`.
- Образ: `teamspeaksystems/teamspeak6-server:6.0.0-beta12.1`.
- Источник compose-файла: `/home/Dockhand/data/stacks/120 - TeamSpeak/teamspeak/compose.yaml` на узле Dockhand.
- Файл окружения: `/home/Dockhand/data/stacks/120 - TeamSpeak/teamspeak/.env` на узле Dockhand.
- Рабочая копия Hawser: `/data/stacks/teamspeak/{compose.yaml,.env}` внутри контейнера `hawser` на целевом узле.
- Постоянные данные: `/home/teamspeak/data` -> `/var/tsserver`.
- Docker-сеть: внешняя `frontend`.

Стек создан штатным API Dockhand как internal stack `teamspeak` в окружении `120 - TeamSpeak` (ID `21`). Dockhand хранит исходные `compose.yaml` и `.env` в своём каталоге, передаёт рабочие копии агенту Hawser и управляет дальнейшими операциями Compose. В `/home/teamspeak` на целевом узле находится только каталог `data`; compose-файлов и `.env` там нет.

## Сетевые порты

- `9987/udp` — голосовой сервер;
- `30033/tcp` — передача файлов.

ServerQuery SSH (`10022/tcp`) и HTTP WebQuery (`10080/tcp`) включены для интеграции с TS6 Manager, но наружу не опубликованы. Они доступны контейнеру менеджера только через общую Docker-сеть `frontend`.

## Настройки

- лицензионное соглашение принимается переменной `TSSERVER_LICENSE_ACCEPTED=accept`;
- политика перезапуска: `unless-stopped`;
- включён `no-new-privileges`;
- core dump отключены через `ulimits.core: 0`;
- пароль встроенной Query-учётной записи `serveradmin` переопределён отдельной секретной переменной Dockhand и отсутствует в `.env`;
- в `query_ip_allowlist.txt` добавлена внутренняя подсеть Docker `172.18.0.0/16`, чтобы последовательные запросы панели TS6 Manager не блокировались защитой Query от флуда.
- группа по умолчанию Guest (ID `8`) имеет только техническое право `b_virtualserver_token_use=1`: новые пользователи остаются в безголосом лобби до персонального подтверждения и не могут пользоваться каналами, голосом, чатом или файлами;
- после нажатия приватной кнопки TeamSpeak применяет одноразовый privilege key и добавляет клиента в постоянную группу `Verified` (ID `10`) с базовыми правами; существующие пользователи перенесены в неё заранее.

Виртуальный сервер оформлен как `🎮 Ammatias Game Hub`, защищён паролем и содержит постоянную структуру каналов Minecraft, Counter-Strike 2, World of Tanks и общего общения. Добавлены приветствие, сообщение хоста и игровой значок. Полная структура и проверка описаны в `teamspeak-decoration.md`; секрет подключения в репозитории не хранится.

Ограничение core dump добавлено после того, как TS6 beta создал файл `core.1` размером около 364 MiB при штатной остановке по `SIGTERM` во время первого пересоздания контейнера. Дамп удалён после диагностики. При последующей работе новых дампов и ошибок запуска нет.

## Лицензия и ограничения beta

На момент запуска сервер сообщает режим `No License`: один виртуальный сервер, до 32 слотов, срок встроенного разрешения до 2026-10-01. TeamSpeak 6 Server находится в beta; совместимость лицензий TeamSpeak 3 и миграция с TeamSpeak 3 официально не поддерживаются.

## Проверка

- API Dockhand возвращает стек `teamspeak` со статусом `running` и типом `internal`;
- API Dockhand возвращает сохранённые пути `compose.yaml` и `.env` из `/app/data/stacks/120 - TeamSpeak/teamspeak`;
- журнал Dockhand содержит успешный результат создания и развёртывания через Hawser;
- контрольные суммы исходных файлов Dockhand и рабочих копий Hawser совпадают;
- Hawser отвечает `{"status":"healthy"}`;
- контейнер имеет состояние `running`, `RestartCount=0`;
- Compose labels указывают на `/data/stacks/teamspeak/compose.yaml`;
- контейнер подключён к сети `frontend`;
- в `/home/teamspeak` отсутствуют обычные файлы, расположен только каталог данных контейнера;
- узел слушает `9987/udp` и `30033/tcp` на IPv4 и IPv6;
- `30033/tcp` доступен с соседнего узла Homepage;
- после повторного развёртывания сохранена исходная SQLite-база, что подтверждает постоянство данных;
- в свежем журнале нет `error`, `critical`, `failed` или `exception`.
- после оформления в SQLite сохранены 18 постоянных каналов с корректной иерархией;
- пароль сервера и игровой значок активны;
- HTTP и SSH Query включены только внутри сети `frontend`; `10080/tcp` и `10022/tcp` не опубликованы на хосте;
- TS6 Manager успешно обращается через WebQuery к виртуальному серверу, видит 18 каналов и получает сводку Dashboard.
- новый неподтверждённый клиент получает группу Guest и остаётся в лобби; персональная кнопка подтверждения выдаёт группу `Verified`, после чего доступ к обычным каналам работает.

Предупреждение `Unable to open /var/tsserver/licensekey.dat` ожидаемо для режима без отдельного файла лицензии.

## Администрирование и откат

Первичный ServerAdmin privilege key выдан в результате развёртывания и намеренно не записан в репозиторий. После его использования клиентом ключ становится одноразовым.

Все изменения, перезапуски и обновления стека следует выполнять через Dockhand в окружении `120 - TeamSpeak`. Для остановки без удаления данных используется операция Compose `down` без удаления volumes. Данные находятся отдельно в `/home/teamspeak/data`; их не следует удалять при обычном обновлении или пересоздании контейнера.
